## 1. 项目概述

### 1.1 目标

1. 用 **pygame** 实现一个完整可玩的 15×15 五子棋游戏（人机对战、双人对战、AI 观战、回放）。
2. 训练一个**完全自研**的强化学习 AI：从零开始、仅靠自对弈学会下棋（AlphaZero 风格），不使用任何他人的开源 AI 模型、预训练权重、RL 库或现成棋类 AI 组件。
3. v1 棋力目标：稳定击败随机/贪心基线，并显著强于限时纯 MCTS 基线；训练管线可持续运行、后续继续增强。

### 1.2 自研边界（关键承诺）

| 类别 | 内容 | 归属 |
|---|---|---|
| 允许的基础设施 | Python 标准库、NumPy（数组运算）、pygame（图形/事件）、PyTorch 张量运算与自动微分、CUDA 运行时 | 通用计算/图形工具，非 AI 组件 |
| 完全自研 | 规则引擎、棋盘状态编码、对称变换、神经网络结构设计与实现、初始化方案、MCTS/PUCT 全部逻辑、自对弈管线、训练循环与损失函数、优化配置、评估系统、UI 与 AI 集成 | 本项目核心 |
| 明确禁止 | 任何预训练权重/模型文件；任何他人开源的棋类 AI、MCTS、AlphaZero/强化学习实现（不参考、不复制其代码）；stable-baselines 等 RL 库；torchvision/timm 等模型组件库 | — |

> PyTorch 在本项目中的角色：仅作为「GPU 张量计算 + 自动微分」引擎（相当于编译器/计算库）。所有 AI 逻辑与结构均为本项目自行设计实现，并以依赖白名单审计（`tools/dep_audit.py`，M1 落地）保证长期合规。

### 1.3 范围与非目标

- 范围内：15×15 标准五子棋（自由规则、无禁手）、AI 训练与评估、人机交互、训练数据与模型管理。
- v1 非目标：禁手/连珠规则、联机对战、Swap2 开局规则、多 GPU 分布式训练、发布安装包（M5 视情况决定）。

## 6. 训练方案概要（详见 DESIGN.md）

- **范式**：AlphaZero 风格自对弈强化学习——MCTS 搜索产出策略目标 π，对局结果产出价值目标 z。
  - 搜索：PUCT，`Q(s,a) + c_puct · P(s,a) · √N(s) / (1 + N(s,a))`
  - 目标：终局以“当前玩家视角”归一化 z = ±1（满盘和棋 z = 0）。
- **数据**：自对弈每步记录 (状态, π, z)；D4 对称群 8 种增强；经验池保留最近 N 局并随机采样。
- **训练**：`L = (z − v)² − πᵀ log p + λ‖θ‖²`；策略/价值双头联合训练；每 K 步触发评估门。
- **评估**：新网 vs 当前最佳，强制黑白交换共 200 局，胜率 ≥ 55% 才采纳并更新“最佳”checkpoint。
- **算力预算（4060 8GB，估算）**：
  - 网络约 7.2M 参数（约 29MB），batch 512 训练显存远低于 8GB；
  - 自对弈约 2–5 秒/局（200 次模拟/步，批量叶子评估）→ 500 局/迭代约 20–40 分钟；
  - 预计 **2–5 天 GPU 时间**达到 v1 棋力目标（数十次迭代）；后续持续训练可继续增强。
